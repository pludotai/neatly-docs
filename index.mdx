neatly.ai helps insurance operations teams run carrier appointment workflows through a single operational workspace. It combines carrier-specific Skyvern workflows, reusable credentials and email content, scheduled follow-ups, OTP delivery, and run artifacts.

The product has two services:

- **Web application** — authenticated workspace for configuring carriers, creating appointments, supplying workflow inputs, and reviewing run status and files.
- **Email service** — Go service for sending Microsoft Graph mail and forwarding verification emails to Skyvern.

<Note>
  The repository contains an active implementation plus workflow research for future carrier coverage. Pages marked as planned describe the current direction, not a committed release date.
</Note>

## Feature areas

- [Carriers](/features/carriers) define ordered Skyvern workflows and branching checks.
- [Credentials](/features/credentials) store the local reference to a Skyvern password credential and optional email TOTP identifier.
- [Email templates](/features/email) provide carrier-scoped body content for workflow inputs.
- [Files](/features/files) move Skyvern downloads into S3-compatible storage and expose short-lived downloads.
- [OTP](/features/otp) connects verification mail to Skyvern's TOTP inbox.
- [Email service](/services/email-service) exposes authenticated mail and TOTP forwarding endpoints.
